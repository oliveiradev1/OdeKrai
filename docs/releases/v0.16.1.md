# v0.16.1 — Google Calendar e controles do Windows

Esta versão adiciona habilidades do Google Calendar e controles locais com aprovação.

Novidades

- Conexão Google Calendar com habilidades Rust separadas, aprovação de escritas e escopo `calendar.events.owned`.
- Habilidades de papel de parede com restauração pelo estado anterior e bloqueio do Windows com aprovação obrigatória; bloqueio negado para origem em conteúdo externo.
- Habilidades MCP públicas: o código inclui o catálogo, OAuth GitHub/Notion/Lovable, a alternativa PAT do GitHub e cartões Google Workspace em Developer Preview. A autenticação não ativa ferramentas: cada ferramenta continua desativada até a pessoa ativá-la.
- Configuração do desenvolvedor: OAuth GitHub requer client ID e segredo do aplicativo; Google requer client ID, segredo e inscrição no Developer Preview. PAT do GitHub é fornecido pela pessoa. Notion e Lovable podem usar registro dinâmico quando anunciado pelos metadados do serviço.
- Validação: as rotas têm testes automatizados com dados e servidores simulados. Conexão de contas reais, configuração de client IDs de distribuição e validação visual/ OAuth no Windows continuam pendentes. Figma permanece indisponível até o OdeKrai ser aceito no catálogo MCP da Figma.
